# Version basica anterior a los assets y power-ups

Proyecto Unity independiente (6000.5.5f1). Anadir esta carpeta a Unity Hub y abrir
Assets/0_0Scenes/Level1.unity. No abrirla como una escena del proyecto principal.

Incluye jugador rectangular, movimiento, salto simple, disparos desde shootp,
enemigos cuadrados melee y tiradores que no se pueden empujar, cinco puntos de
vida, checkpoint, camara y meta con bandera. Interfaz minima. Sprites blancos,
sin decoracion de fondo, sin CharacterPhysics, animaciones ni power-ups.

A/D: mover. Espacio: saltar. J o clic: disparar. R: volver al checkpoint.

La escena se recupero de la copia guardada justo antes de integrar los assets.
Los scripts se reconstruyeron para conservar las mecanicas basicas de esa etapa.
El proyecto principal mantiene su version actual con Jungle y power-ups.
Library, Logs y otras caches se generan al abrir Unity y no forman parte de la copia.
